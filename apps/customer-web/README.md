# LOADIN Customer Web

Step 33 customer UI scaffold for the LOADIN logistics marketplace.

## Included
- LOADIN orange + navy visual baseline
- Responsive mobile-first customer shell
- Home / My Bookings / Support / Account navigation
- AI Smart Booking form
- Goods + pickup + drop + Now/Schedule inputs
- Four locked services: 2-Wheeler Parcel, Loading Vehicle, Helper, Full Shifting
- AI Best Match / Best Value / Fastest Arrival cards
- Fare Lock treatment
- Book Again interaction
- Support and account placeholder flows

## Run locally
Open `index.html` through a local static HTTP server. No build step or third-party dependency is required for this scaffold.

## Next integration
